Settings & backup

Your watch progress is saved automatically on this device in this website's local storage. It syncs between lists, but not automatically between devices. For reliable Home Screen use, host this HTML on an HTTPS website and add that website to your Home Screen.

Backups are JSON files you can keep in Files or iCloud Drive. Import them if you change phones, clear Safari website data, or use a different browser.
